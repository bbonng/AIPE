# AIPE — 체육수업 전문가 페르소나

수업 고민이 있을 때 분야별 AI 전문가와 대화하는 체육교사용 웹앱입니다.
**AI 체육수업 실천 연구회**에서 만들었습니다.

- 서버 없음 · 운영비 0원 — 정적 웹페이지 + 각자의 무료 Gemini API 키
- 대화 내용과 API 키는 사용자 브라우저에만 있으며 어디에도 수집되지 않습니다

## 사용 방법 (교사용)

1. 앱 페이지에 접속합니다 (GitHub Pages 주소 또는 `index.html` 파일 열기)
2. **⚙️ API 키 설정** 버튼 클릭
3. [Google AI Studio](https://aistudio.google.com/apikey)에서 무료 API 키를 만들어 붙여넣기 (약 1분, 결제 등록 불필요)
4. 원하는 전문가 카드를 눌러 대화 시작

> ⚠️ **학생의 실명·학번 등 개인정보는 절대 입력하지 마세요.** "학생 A"처럼 익명으로 질문합니다.
> AI 답변은 초안·참고용이며, 최종 검토와 판단은 교사의 몫입니다.

## 페르소나 목록

| 페르소나 | 하는 일 |
|---|---|
| 🎪 원탁회의 | 고민 하나에 관련 전문가 2~3명이 서로 다른 방향 제시·반박, 진행자가 쟁점 정리 |
| 🏃 수업설계 코치 | 성취기준 기반 단원·차시 지도안 설계, 변형 게임·수준별 과제 |
| 📋 평가·루브릭 전문가 | 수행평가 계획, 채점기준표, 자기·동료평가지 |
| ✍️ 생기부 문구 도우미 | 관찰 키워드 → 과세특 문구 초안 (생기부 문체) |
| 🌧️ 실내수업 아이디어 뱅크 | 우천·미세먼지·폭염 대비 교실/강당 활동 |
| 🎒 운동 기피 학생 | 수업 아이디어를 학생 시점에서 시큰둥하게 리뷰 (해결책 없이 감상만) |
| 👴 30년차 선배 교사 | 경험 기반 현실 검증 — 반드시 실패 시나리오 하나를 짚음 |
| 🌐 3사 회담 (실험) | Claude·Gemini·GPT 실제 3개 AI가 2라운드 토론 후 진행자 정리 |

### 🎪 원탁회의
- API 호출은 1번이며, Gemini 하나가 진행자와 전문가들을 모두 연기합니다.
- 참석자 명단은 `personas.js`의 `ROUNDTABLE_MEMBERS` 목록으로 관리합니다. 새 전문가를 PERSONAS에 추가하고 id를 이 목록에 적으면 원탁회의에 자동 합류합니다.

### 🌐 3사 회담 (실험 기능)
- 실제로 서로 다른 3개 회사의 AI를 호출합니다: 라운드 1(각자 답) → 라운드 2(서로 반박) → 진행자 정리(Gemini).
- ⚙️ 설정에서 Anthropic/OpenAI 키(**유료 종량제**)를 추가해야 열립니다. 키가 2개면 2사 회담으로 동작합니다.
- 사용 모델은 `index.html`의 `MODEL_IDS` 상수 한 곳에서 변경합니다.

## 페르소나 추가·수정 방법 (연구회 회원용)

코드를 몰라도 됩니다. **`personas.js` 파일 하나만** 수정하면 됩니다.

1. `personas.js`를 열어 기존 페르소나 블록(`{ ... }`)을 복사
2. `PERSONAS` 배열 맨 뒤에 붙여넣고 내용 수정:
   - `id`: 영문, 다른 것과 겹치지 않게
   - `emoji`, `name`, `tagline`, `description`: 카드에 표시되는 내용
   - `starters`: 대화 시작 예시 질문 (3개 권장)
   - `prompt`: **가장 중요.** 전문가의 역할, 지식, 답변 규칙을 자세히 쓸수록 답변이 좋아집니다
3. 저장하고 새로고침하면 카드가 추가됩니다

## 배포 (GitHub Pages)

이 저장소의 **Settings → Pages → Branch: main, / (root)** 를 선택하면
`https://<계정명>.github.io/AIPE/` 주소로 누구나 접속할 수 있습니다.

```

```

## 비용에 대해

Google Gemini API의 **무료 등급**을 사용합니다. 교사 개인 구글 계정으로 키를 만들면
결제 정보 없이 하루 수백 회 수준의 대화가 가능해 개인 수업 준비 용도로는 충분합니다.
한도 초과 시 잠시 후 다시 시도하거나, 설정에서 Flash-Lite 모델로 바꾸면 됩니다.
