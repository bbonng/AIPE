# 체육과 평가 운영 계획 설계 에이전트 (AIPE)

체육 교사가 Claude와 **대화만으로** 「(체육)과 교수학습 및 평가 운영 계획」(1부 평가 계획 · 2부 진도표 · 3부 성취수준) DOCX 문서를 완성하는 에이전트 패키지입니다.

한 번 만들어 배포하면, 각 교사가 자신의 Claude 계정에서 **자기 종목·자기 수업의 평가표**를 만들 수 있습니다. 서버도, API 키도 필요 없습니다.

## 구성

```
claude-project/
├── 지침.md                        ← Claude 프로젝트 '지침'에 붙여넣는 내용
└── 지식/
    ├── 성취기준_중학교_체육.md      ← 2022 개정 교육과정 성취기준 51개
    └── JSON_스키마.md              ← 문서 데이터 구조 정의
scripts/
└── make_docx.py                   ← JSON → DOCX 변환기 (python-docx)
data/
└── 성취기준_중학교_체육.json       ← 성취기준 원본 데이터
examples/
└── 예시_피클볼.json               ← 완성 데이터 예시 (2학년 피클볼 8차시)
```

## 교사용 설치 방법 (5분)

1. [claude.ai](https://claude.ai) 로그인 → **프로젝트 만들기** (이름 예: "체육과 평가계획 도우미")
2. 프로젝트 **지침**에 `claude-project/지침.md` 내용 전체를 붙여넣기
3. 프로젝트 **지식**에 다음 3개 파일 업로드:
   - `claude-project/지식/성취기준_중학교_체육.md`
   - `claude-project/지식/JSON_스키마.md`
   - `scripts/make_docx.py`
4. 대화 시작:

   > "2학년 피클볼 17차시, 평가는 4~6월이야. 평가계획서 만들어줘."

에이전트가 부족한 정보만 물어본 뒤, 수행평가(루브릭) → 진도표 → 성취수준 순서로 백워드 설계하고, 단계마다 확인을 받고, 자체 검증 후 DOCX 파일을 만들어 줍니다. 완성 후 "6차시만 수행평가로 바꿔줘" 같은 부분 수정도 됩니다.

Claude Code(터미널/웹) 사용자는 이 저장소를 열고 바로 같은 요청을 하면 됩니다.

## 수동 변환 (파일 생성이 안 되는 환경일 때)

Claude가 출력한 JSON을 파일로 저장한 뒤:

```bash
pip install python-docx
python3 scripts/make_docx.py 내설계.json
```

앞뒤에 설명 텍스트나 마크다운 코드블록이 섞여 있어도 자동으로 걸러냅니다. 생성 전에 배점 합계·시수 합계·루브릭↔성취수준 정합성을 자동 검증합니다.

## 연구 배경

| | 1세대 (2026.3, [bongs](https://github.com/bbonng/bongs)) | 2세대 (본 저장소) |
|---|---|---|
| 입력 | 6단계 폼 위저드 | 대화형 인터뷰 (부족한 것만 질문) |
| Claude 연결 | 프롬프트 복사 → claude.ai → JSON 복사 → 붙여넣기 | 프로젝트 지침 + 지식 파일 (복붙 없음) |
| 생성 방식 | 1·2·3부 원샷 생성 (응답 잘림 취약) | 단계별 생성 + 단계별 교사 확인 |
| 검증 | 없음 | 배점·시수·성취기준 커버리지·탐구질문 중복 자동 검증 |
| 수정 | 전체 재생성 | 부분 수정 후 재검증·재생성 |
| 산출 | 브라우저 내 docx.js | python-docx (`make_docx.py`), 동일 서식 (A3 세로) |

1세대의 자산(성취기준 DB, 백워드 설계 원칙 7개, 1·2·3부 문서 서식)은 그대로 이식했고, 사람이 복사-붙여넣기로 전송 계층 역할을 하던 구조를 에이전트로 대체한 것이 핵심 차이입니다.
